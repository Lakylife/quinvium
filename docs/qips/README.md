# Quinvium Improvement Proposals (QIPs)

A QIP describes one change to the consensus rules of Quinvium. The process and its time limits are in [GOVERNANCE.md](../GOVERNANCE.md).

| QIP | Title | Status |
| --- | --- | --- |
| [QIP-1](qip-0001.md) | QIP process and consensus guard | Final |

To propose a change, copy [qip-template.md](qip-template.md) to `qip-XXXX.md` and open a pull request. The number is assigned when the draft is merged.
