Pools

        
In a pool you get paid for your share of the work, so income stays steady even with a small card. A contract holds the rewards, so the operator cannot take them.

          Connections and access
          
Computers on the same network find each other. Enter an address only if they do not connect.

          

          
          
          
Recommended. The router opens only the port for connections between nodes, so the network stays connected when a server is down. The wallet, the Explorer and mining stay closed to others.

          

          
          

          
          
Without a public address filled in, the node asks the service api.ipify.org for it, so that service learns the address of this computer. Mining is served only to this computer and the local network.

          

          
          
Helps the network: wallets and the Explorer can use your node when the main servers are down. It goes through a Cloudflare tunnel, so your IP address stays hidden and no port on the router is opened. It uses your upload bandwidth (usually a few hundred MB a day) and runs only while this app and its node run. Cloudflare sees the requests that pass through.

About

        

          

          
Quinvium

        

        
Quinvium is an independent proof-of-work blockchain compatible with Ethereum smart contracts. Anyone can run a node and mine with a graphics card. There is no premine, and all fees go to the miners.

        

          
          
Quinvium QU
Its coin, Quinvium (QU), can only be mined. No coin was created in advance, every one comes from real work.
