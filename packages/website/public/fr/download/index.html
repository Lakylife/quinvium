Premier lancement

macOS

Décompressez et déplacez Quinvium dans Applications. Au premier lancement, macOS indique qu’il ne peut pas vérifier le développeur : ouvrez Réglages Système → Confidentialité et sécurité et cliquez sur Ouvrir quand même, ou faites un clic droit sur l’app et choisissez Ouvrir. L’app est compilée pour Intel ; les Mac Apple Silicon l’exécutent via Rosetta.

Windows

Lancez le programme d’installation. Si SmartScreen affiche « Windows a protégé votre ordinateur », cliquez sur Informations complémentaires → Exécuter quand même. Le zip portable fonctionne sans installation.

Portefeuille Chrome

  1. Décompressez le fichier dans un dossier que vous garderez.
  2. Ouvrez chrome://extensions et activez le Mode développeur.
  3. Cliquez sur Charger l’extension non empaquetée et choisissez le dossier décompressé.

Vérifiez la somme de contrôle

shasum -a 256 -c SHA256SUMS.txt --ignore-missing     # macOS, Linux
certutil -hashfile Quinvium-2.16.0-Windows-x64.exe SHA256    # Windows

Ne téléchargez que depuis quinvium.com. Les builds d’autres sources peuvent être falsifiés. Les mises à jour à distance sont désactivées sur le mainnet ; les nouvelles versions s’installent donc à la main depuis cette page.
