Miner Quinvium

Une carte graphique, l’app et une adresse de paiement. C’est tout.

Ce qu’il vous faut

Une carte graphique

AMD ou NVIDIA avec au moins 2 Go de mémoire. Les données de l’algorithme (DAG) grandissent avec le temps, donc plus de mémoire tient plus longtemps. Les ASIC Ethash sont aussi autorisés.

Une adresse de paiement

N’importe quelle adresse 0x… de votre portefeuille. Les récompenses y sont versées directement.

Une connexion

Le nœud rejoint le réseau tout seul via seed.quinvium.com.

Minage dans l’app Quinvium

  1. Installez l’app pour macOS ou Windows. Télécharger
  2. Choisissez le réseau Mainnet. L’app démarre son propre nœud et télécharge la chaîne.
  3. Dans Minage, saisissez votre adresse de paiement et activez le minage.

Votre propre nœud et mineur

Le nœud en ligne de commande et le mineur GPU quintium-miner :

quintium-node --network mainnet --miner-address YOUR_ADDRESS
quintium-miner --address YOUR_ADDRESS --node http://127.0.0.1:8545

Le nœud propose aussi Stratum (port 3333), donc d’autres mineurs Ethash fonctionnent aussi. Pour les mineurs de votre réseau local, lancez le nœud avec --stratum-host 0.0.0.0.

Le nœud dans Docker

Sur un serveur ou un ordinateur avec Docker, le nœud démarre en une commande. L’image existe pour amd64 et arm64 ; les données restent dans un volume.

docker run -d --name quinvium --restart unless-stopped   -p 30524:30524 -p 3333:3333 -p 127.0.0.1:8545:8545   -v quinvium-mainnet:/data ghcr.io/lakylife/quinvium-node:latest   --network mainnet --miner-address YOUR_ADDRESS --stratum-host 0.0.0.0

Pointez ensuite votre mineur vers stratum+tcp://COMPUTER_ADDRESS:3333. Sans --miner-address ni le port 3333, c’est un nœud qui aide le réseau. D’autres options dans Running a public node.

Solo ou pool

Solo

Vous recevez le bloc entier et ses frais, mais avec une seule carte l’attente entre deux blocs peut être longue.

Pool par contrat

La fabrique de pools est intégrée au réseau. Un pool compte les parts des mineurs et le contrat verse les récompenses en conséquence. Le Quinvium Pool officiel tourne sur pool.quinvium.com avec des frais de 1 %.

Gérer un pool

Un pool sur Quinvium est un contrat intelligent issu de la fabrique du réseau. Les récompenses vont directement dans le contrat, qui les répartit selon le travail prouvé (PPLNS) ; l’opérateur ne peut prendre que ses frais fixes, 5 % au plus.

  1. 1

    Créez le contrat

    Dans l’Explorer, Pools → Créer un pool, ou :

    quinvium pool create --name "My Pool" \
  --url https://pool.example.org --fee-percent 1
  2. 2

    Lancez le serveur du pool

    Un nœud avec --pool. Le compte du nœud paie le gas des parts ; envoyez-lui un peu de QU.

    node packages/node/src/cli.js --network mainnet \
  --pool 0xPOOL --stratum-port 4444
  3. 3

    Attirez des mineurs

    Les mineurs se connectent avec le mineur ou via Stratum et retirent leurs gains dans l’app ou l’Explorer.

    quintium-miner --address YOUR_ADDRESS \
  --node https://pool.example.org --pool 0xPOOL

Difficulté

La difficulté s’ajuste après chaque bloc selon les 60 derniers blocs (LWMA). Quand de la puissance arrive, les blocs accélèrent un moment et la difficulté rattrape en quelques minutes. Quand elle part, elle se stabilise de la même façon. La difficulté minimale est 224.

Questions sur le minage

Combien vais-je miner ?
Votre part du hashrate du réseau multipliée par 4 QU par bloc. Environ 5 760 blocs sont produits par jour, soit à peu près 23 040 QU pour tout le réseau. Le hashrate actuel figure sur la page d’accueil et dans l’Explorer.
Quand la récompense arrive-t-elle ?
Immédiatement avec le bloc. La récompense fait partie du bloc que vous minez.
Puis-je miner sur un serveur cloud ?
Cela dépend des conditions du fournisseur. Beaucoup interdisent le minage.
