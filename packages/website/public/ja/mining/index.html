Quinvium のマイニング

グラフィックカード、アプリ、受け取りアドレス。それだけです。

必要なもの

グラフィックカード

メモリ 2 GB 以上の AMD または NVIDIA。アルゴリズムのデータ（DAG）は時間とともに増えるため、メモリが多いほど長く使えます。Ethash の ASIC も使えます。

受け取りアドレス

ウォレットの任意の 0x… アドレス。報酬は直接そこに支払われます。

接続

ノードは seed.quinvium.com を通じて自動でネットワークに参加します。

Quinvium アプリでマイニング

  1. macOS または Windows 用のアプリをインストールします。ダウンロード
  2. Mainnet を選びます。アプリが独自のノードを起動してチェーンをダウンロードします。
  3. 「マイニング」で受け取りアドレスを入力し、マイニングをオンにします。

独自のノードとマイナー

コマンドラインのノードと GPU マイナー quintium-miner：

quintium-node --network mainnet --miner-address VAŠE_ADRESA
quintium-miner --address VAŠE_ADRESA --node http://127.0.0.1:8545

ノードは Stratum（ポート 3333）も提供するので、他の Ethash マイナーも使えます。ローカルネットワークのマイナー向けには --stratum-host 0.0.0.0 でノードを起動します。

ソロかプールか

ソロ

ブロックと手数料をすべて受け取れますが、カード 1 枚だとブロック間の待ち時間が長くなることがあります。

コントラクトプール

プールファクトリーはネットワークに組み込まれています。プールがマイナーのシェアを数え、コントラクトがそれに応じて報酬を支払います。公式の Quinvium Pool は pool.quinvium.com で手数料 1 % で稼働しています。

プールを運営する

Quinvium のプールは、ネットワークのファクトリーから作られるスマートコントラクトです。報酬は直接コントラクトに入り、証明された作業に応じて分配されます（PPLNS）。運営者が受け取れるのは固定手数料（最大 5 %）だけです。

  1. 1

    コントラクトを作成

    エクスプローラーの「プール → プールを作成」、または：

    quinvium pool create --name "My Pool" \
  --url https://pool.example.org --fee-percent 1
  2. 2

    プールサーバーを起動

    --pool を付けたノード。シェアのガス代はノード自身のアカウントが支払うので、少し QU を送っておきます。

    node packages/node/src/cli.js --network mainnet \
  --pool 0xPOOL --stratum-port 4444
  3. 3

    マイナーを集める

    マイナーはマイナーソフトまたは Stratum で接続し、アプリやエクスプローラーで収益を引き出します。

    quintium-miner --address YOUR_ADDRESS \
  --node https://pool.example.org --pool 0xPOOL

プールの完全ガイドエクスプローラーのプール

難易度

難易度はブロックごとに直近 60 ブロックから調整されます（LWMA）。ハッシュレートが増えるとしばらくブロックが速くなり、数分で難易度が追いつきます。減った場合も同様に落ち着きます。最低難易度は 224 です。

マイニングの質問

どれくらいマイニングできますか？
ネットワークのハッシュレートに占めるあなたの割合 × 1 ブロック 4 QU です。1 日に約 5,760 ブロック、ネットワーク全体で約 23,040 QU が生まれます。現在のハッシュレートはトップページとエクスプローラーで確認できます。
報酬はいつ届きますか？
ブロックと同時にすぐ届きます。報酬はマイニングしたブロックの一部です。
クラウドサーバーでマイニングできますか？
プロバイダーの規約次第です。多くはマイニングを禁止しています。
