セキュリティ

正直に言うと、コードは十分にテストされていますが、独立監査はまだ行われていません。

現状

  • ノード、コントラクト、ウォレット、エクスプローラーの自動テスト（Ethereum 公式の EVM テストスイートを含む）。
  • 2026年11月7–8日、10日、13日に社内コードレビューを実施し、指摘事項を修正済み。
  • 独立したセキュリティ監査はまだ行われていません。
  • 署名鍵を開発用マシンの外へ移すまで、メインネットではアプリのリモート更新を停止しています。
  • 現在、ネットワークは 1 台の公開サーバーとマイナーのノードで支えられています。

脆弱性の報告

脆弱性は GitHub で非公開で報告してください：Report a vulnerability。修正前に公開しないでください。

リスク

Quinvium は実験的なソフトウェアです。小さなプルーフ・オブ・ワークのネットワークは、借りたハッシュレートで一時的に書き換えられることがあるため、大きな支払いではより多くの承認を待ってください。失っても困らない額以上は保管しないでください。
