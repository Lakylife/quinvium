Hardhat：hardhat.config.js にネットワークを追加します：

networks: {
  quinvium: { url: 'https://rpc.quinvium.com', chainId: 52401, accounts: [process.env.KEY] },
  quinviumTestnet: { url: 'https://rpc1.quinvium.com', chainId: 52402, accounts: [process.env.KEY] },
}

JSON-RPC

  • 標準の eth_*、net_*、web3_* メソッド（WebSocket の購読を含む）。
  • エクスプローラー用の追加メソッド quinvium_*：統計、アドレス、トークン、マイナー、プール、検索。
  • 公開ノードではマイニング用メソッド（eth_getWork、eth_submitWork）が無効で、リクエスト数に制限があります。
