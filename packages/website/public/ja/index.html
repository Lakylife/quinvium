Quinvium を選ぶ理由

マイナーが守り、Ethereum を知っていれば誰でも使えるネットワーク。

完全な EVM、使い慣れたツール

Solidity、ethers.js、Hardhat、MetaMask はそのまま動きます。公開 RPC を指定してデプロイするだけです。

const provider = new ethers.JsonRpcProvider(
  'https://rpc.quinvium.com', 52401);
await provider.getBlockNumber();

グラフィックカードでマイニング

一般的な AMD や NVIDIA のカードで Ethash。ブロックはステークの大きさではなく、行われた作業に基づきます。

フェアローンチ

プレマインなし、プレセールなし、企業も所有者もなし。

手数料はマイナーへ

手数料はバーンされません。ブロックのマイナーがすべて受け取ります。

よくある質問

QU はどう入手しますか？
マイニングするか、QU を持つ人から送ってもらいます。プレセールも取引所もありません。
開始前にコインを受け取った人はいますか？
いいえ。ジェネシスに残高はなく、すべての QU は誰かがマイニングしたものです。
MetaMask は使えますか？
はい、ほかの EVM ネットワークと同じです。上のボタンでネットワークを追加してください。
監査は行われましたか？
社内レビューは実施済みですが、独立監査はまだです。Quinvium は実験的なソフトウェアです。
