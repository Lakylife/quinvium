約束ではなく意図です。日付は決まっているものだけです。

  1. 完了ノード、EVM、GPU マイニング、コントラクトプール、8 言語のエクスプローラー、macOS と Windows のアプリ、Chrome ウォレット、Wpayin、コマンドライン、公開テストネット。
  2. 2026年11月14日メインネット開始、公開ノード rpc.quinvium.com とエクスプローラー。
  3. 2026年11月公式プール pool.quinvium.com、コミュニティが運営する2つ目のシード、アプリからのノード共有、そしてサーバー停止時にウェブサイト、Explorer、ウォレットがコミュニティのノードへ切り替わる仕組み。
  4. 次に独立したセキュリティ監査。Explorer でのコントラクトのソースコード検証。ノードの Docker イメージ。更新署名鍵を開発用コンピューターの外へ移し、リモート更新を再開。署名済みの Windows 版と Chrome ウェブストアでのウォレット公開。
  5. その後マルチシグ管理によるメインネットでのスワップと検証済みトークンリスト。独立したバリデーターによるブリッジ。大量のトラフィックに向けたコンパクトブロックとステートの剪定。
