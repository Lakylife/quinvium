التشغيل الأول

macOS

فك الضغط وانقل Quinvium إلى التطبيقات. عند التشغيل الأول سيقول macOS إنه لا يستطيع التحقق من المطوّر: افتح إعدادات النظام ← الخصوصية والأمان وانقر افتح على أي حال، أو انقر بزر الفأرة الأيمن على التطبيق واختر فتح. التطبيق مبني لمعالجات Intel؛ وتشغّله أجهزة Mac بمعالج Apple Silicon عبر Rosetta.

Windows

شغّل المثبّت. إذا عرض SmartScreen «Windows protected your PC» فانقر More info ← Run anyway. ملف zip المحمول يعمل دون تثبيت.

محفظة Chrome

  1. فك ضغط الملف في مجلد ستحتفظ به.
  2. افتح chrome://extensions وشغّل وضع المطوّر.
  3. انقر تحميل إضافة غير مضغوطة واختر المجلد الذي فككت ضغطه.

تحقّق من المجموع الاختباري

shasum -a 256 -c SHA256SUMS.txt --ignore-missing     # macOS, Linux
certutil -hashfile Quinvium-2.16.1-Windows-x64.exe SHA256    # Windows
