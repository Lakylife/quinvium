First launch

macOS

Unzip and move Quinvium to Applications. On first launch macOS says it cannot verify the developer: open System Settings → Privacy & Security and click Open Anyway, or right-click the app and choose Open. The app is built for Intel; Apple Silicon Macs run it through Rosetta.

Windows

Run the installer. If SmartScreen shows "Windows protected your PC", click More info → Run anyway. The portable zip runs without installing.

Chrome wallet

  1. Unzip the file to a folder you will keep.
  2. Open chrome://extensions and switch on Developer mode.
  3. Click Load unpacked and choose the unzipped folder.

Verify the checksum

shasum -a 256 -c SHA256SUMS.txt --ignore-missing     # macOS, Linux
certutil -hashfile Quinvium-2.15.2-Windows-x64.exe SHA256    # Windows

Download only from quinvium.com. Builds from other sources may be fake. Remote updates are switched off on mainnet, so new versions are installed by hand from this page.
