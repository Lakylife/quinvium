Warum Quinvium

Ein Netzwerk, das Miner absichern und das jeder nutzen kann, der Ethereum kennt.

Volle EVM, vertraute Werkzeuge

Solidity, ethers.js, Hardhat und MetaMask funktionieren unverändert. Richten Sie sie auf das öffentliche RPC aus und deployen Sie.

const provider = new ethers.JsonRpcProvider(
  'https://rpc.quinvium.com', 52401);
await provider.getBlockNumber();

Auf Grafikkarten gemint

Ethash auf einer gewöhnlichen AMD- oder NVIDIA-Karte. Blöcke beruhen auf geleisteter Arbeit, nicht auf der Größe eines Einsatzes.

Fairer Start

Kein Premine, kein Vorverkauf, keine Firma und kein Eigentümer.

Gebühren an Miner

Gebühren werden nicht verbrannt. Der Miner des Blocks erhält sie vollständig.

In einer Minute starten

Das Netzwerk ist offen. Kein Konto und keine Erlaubnis nötig.

  1. 1

    Wallet besorgen

    Die Quinvium-App, Wpayin, die Chrome-Wallet oder MetaMask.

    Wallet wählen
  2. 2

    Netzwerk hinzufügen

    Ein Klick fügt das Quinvium-Mainnet zu MetaMask hinzu.

  3. 3

    Minen oder erkunden

    Schalten Sie das Mining in der App ein oder verfolgen Sie die Chain im Explorer.

Zwölf Verträge sind Teil der Genesis. Sie haben keinen Eigentümer, und niemand kann sie abschalten.

Häufige Fragen

Wie bekomme ich QU?
Durch Mining oder per Überweisung von jemandem, der QU hat. Es gibt keinen Vorverkauf und keine Börse.
Hat jemand vor dem Start Coins bekommen?
Nein. Die Genesis enthält keine Guthaben; jedes QU wird gemint, von jedem.
Funktioniert MetaMask?
Ja, wie bei jedem EVM-Netzwerk. Fügen Sie das Netzwerk mit der Schaltfläche oben hinzu.
Gab es ein Audit?
Interne Prüfungen ja, ein unabhängiges Audit noch nicht. Quinvium ist experimentelle Software.
