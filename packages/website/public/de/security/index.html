Sicherheit

Ehrlich gesagt: Der Code ist gründlich getestet, aber ein unabhängiges Audit gab es noch nicht.

Stand

  • Automatisierte Tests von Knoten, Verträgen, Wallets und Explorer, einschließlich der offiziellen EVM-Testsuite von Ethereum.
  • Interne Code-Prüfungen am 7.–8., 10. und 13. November 2026, mit behobenen Befunden.
  • Ein unabhängiges Sicherheitsaudit gab es noch nicht.
  • Fernupdates der App sind im Mainnet abgeschaltet, bis der Signaturschlüssel vom Entwicklungsrechner wegbewegt ist.
  • Das Netzwerk wird bisher von einem öffentlichen Server und den Knoten der Miner getragen.

Eine Schwachstelle melden

Melden Sie Schwachstellen privat auf GitHub: Report a vulnerability. Bitte veröffentlichen Sie sie nicht vor einer Korrektur.

Risiken

Quinvium ist experimentelle Software. Ein kleines Proof-of-Work-Netzwerk kann mit gemieteter Hashrate kurzzeitig umgeschrieben werden, warten Sie daher bei größeren Zahlungen auf mehr Bestätigungen. Bewahren Sie nicht mehr auf, als Sie verlieren können.
