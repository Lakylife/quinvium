První spuštění

macOS

Rozbalte a přesuňte Quinvium do Aplikací. Při prvním spuštění macOS napíše, že nemůže ověřit vývojáře: otevřete Nastavení systému → Soukromí a zabezpečení a klikněte na Přesto otevřít, nebo na aplikaci klikněte pravým tlačítkem a vyberte Otevřít. Aplikace je sestavená pro Intel; Macy s Apple Silicon ji spustí přes Rosettu.

Windows

Spusťte instalátor. Když SmartScreen ukáže „Systém Windows ochránil váš počítač“, klikněte na Další informace → Přesto spustit. Přenosný zip běží bez instalace.

Peněženka pro Chrome

  1. Rozbalte soubor do složky, kterou si necháte.
  2. Otevřete chrome://extensions a zapněte Režim pro vývojáře.
  3. Klikněte na Načíst rozbalené a vyberte rozbalenou složku.

Ověřte kontrolní součet

shasum -a 256 -c SHA256SUMS.txt --ignore-missing     # macOS, Linux
certutil -hashfile Quinvium-2.16.1-Windows-x64.exe SHA256    # Windows

Stahujte jen z quinvium.com. Sestavení z jiných zdrojů mohou být podvržená. Aktualizace na dálku jsou na mainnetu vypnuté, nové verze se proto instalují ručně z této stránky.
