Rychlý start

import { ethers } from 'ethers';
const provider = new ethers.JsonRpcProvider('https://rpc.quinvium.com', 52401);
console.log(await provider.getBlockNumber());

Hardhat: přidejte síť do hardhat.config.js:

networks: {
  quinvium: { url: 'https://rpc.quinvium.com', chainId: 52401, accounts: [process.env.KEY] },
  quinviumTestnet: { url: 'https://rpc1.quinvium.com', chainId: 52402, accounts: [process.env.KEY] },
}

JSON-RPC

  • Standardní metody eth_*, net_* a web3_* včetně odběrů přes WebSocket.
  • Navíc metody quinvium_* pro Explorer: statistiky, adresy, tokeny, těžaři, pooly, hledání.
  • Veřejné uzly mají těžební metody (eth_getWork, eth_submitWork) vypnuté a limit požadavků.
