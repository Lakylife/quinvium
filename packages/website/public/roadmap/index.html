Quinvium roadmap

Intentions, not promises. Dates only where something is decided.

  1. DoneNode, EVM, GPU mining, contract pools, Explorer in five languages, macOS and Windows app, Chrome wallet, Wpayin, command line, public testnet.
  2. 14 Nov 2026Mainnet launch, public node rpc.quinvium.com and the Explorer.
  3. NextAn independent security audit. A second public node with another provider. An update-signing key off the development machine and remote updates switched back on. Signed Windows builds and the wallet in the Chrome Web Store.
  4. LaterSwap and a verified token list on mainnet under multisig governance. A bridge with independent validators. Compact blocks and state pruning for heavy traffic.
