首次启动

macOS

解压并将 Quinvium 移到“应用程序”。首次启动时 macOS 会提示无法验证开发者：打开系统设置 → 隐私与安全性并点击仍要打开，或右键点击应用选择打开。应用为 Intel 构建，Apple 芯片的 Mac 通过 Rosetta 运行。

Windows

运行安装程序。如果 SmartScreen 显示“Windows 已保护你的电脑”，点击更多信息 → 仍要运行。便携 zip 版无需安装即可运行。

Chrome 钱包

  1. 将文件解压到一个会长期保留的文件夹。
  2. 打开 chrome://extensions 并开启开发者模式。
  3. 点击加载已解压的扩展程序并选择解压后的文件夹。
