挖 Quinvium

一张显卡、应用和一个收款地址，仅此而已。

你需要什么

一张显卡

至少 2 GB 显存的 AMD 或 NVIDIA 显卡。算法数据（DAG）会随时间增长，显存越大能用越久。也允许使用 Ethash ASIC。

一个收款地址

你钱包里的任意 0x… 地址。奖励直接支付到该地址。

网络连接

节点会通过 seed.quinvium.com 自动加入网络。

在 Quinvium 应用中挖矿

  1. 安装适用于 macOS 或 Windows 的应用。下载
  2. 选择主网。应用会启动自己的节点并下载区块链。
  3. 在“挖矿”中输入收款地址并开启挖矿。

自己的节点和矿机程序

命令行节点和 GPU 矿机程序 quintium-miner：

quintium-node --network mainnet --miner-address VAŠE_ADRESA
quintium-miner --address VAŠE_ADRESA --node http://127.0.0.1:8545

节点还提供 Stratum（端口 3333），因此其他 Ethash 矿机程序也能使用。若要让局域网中的矿机连接，请用 --stratum-host 0.0.0.0 启动节点。

单独挖还是矿池

单独挖矿

你会获得整个区块及其手续费，但只有一张显卡时，两次出块之间可能要等很久。

合约矿池

矿池工厂内置于网络。矿池统计矿工的份额，合约据此发放奖励。官方 Quinvium Pool 运行在 pool.quinvium.com，手续费 1%。

运营矿池

Quinvium 上的矿池是由网络工厂创建的智能合约。奖励直接进入合约，按已证明的工作分配（PPLNS）；运营者只能收取固定手续费，最多 5%。

  1. 1

    创建合约

    在浏览器中选择“矿池 → 创建矿池”，或：

    quinvium pool create --name "My Pool" \
  --url https://pool.example.org --fee-percent 1
  2. 2

    运行矿池服务器

    使用 --pool 启动的节点。节点自己的账户支付份额的 gas，请给它转一点 QU。

    node packages/node/src/cli.js --network mainnet \
  --pool 0xPOOL --stratum-port 4444
  3. 3

    吸引矿工

    矿工用矿机程序或通过 Stratum 连接，并在应用或浏览器中提取收益。

    quintium-miner --address YOUR_ADDRESS \
  --node https://pool.example.org --pool 0xPOOL

矿池完整指南浏览器中的矿池

难度

难度在每个区块后根据最近 60 个区块调整（LWMA）。算力加入时，出块会暂时加快，难度在几分钟内跟上；算力离开时也会同样趋稳。最低难度为 224。

挖矿问题

我能挖多少？
你在全网算力中的占比乘以每块 4 QU。每天约产生 5,760 个区块，全网约 23,040 QU。当前算力可在首页和浏览器中查看。
奖励多快到账？
随区块立即到账。奖励是你挖出的区块的一部分。
可以在云服务器上挖矿吗？
取决于服务商的条款。很多服务商禁止挖矿。
