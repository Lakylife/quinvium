Security

Honestly: the code is thoroughly tested, but no independent audit has been done yet.

Status

  • Automated tests of the node, contracts, wallets and Explorer, including the official Ethereum EVM test suite.
  • Internal code reviews on 7–8, 10 and 13 November 2026, with the findings fixed.
  • No independent security audit has been done yet.
  • Remote app updates are off on mainnet until the signing key is moved off the development machine.
  • The network is carried by one public server and the miners' nodes so far.

Reporting a vulnerability

Report vulnerabilities privately on GitHub: Report a vulnerability. Please do not disclose them publicly before a fix.

Risks

Quinvium is experimental software. A small proof-of-work network can be briefly rewritten with rented hashrate, so wait for more confirmations on larger payments. Do not store more than you can afford to lose.
