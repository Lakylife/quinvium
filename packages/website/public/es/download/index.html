Primer arranque

macOS

Descomprima y mueva Quinvium a Aplicaciones. En el primer arranque macOS dirá que no puede verificar al desarrollador: abra Ajustes del Sistema → Privacidad y seguridad y pulse Abrir igualmente, o haga clic derecho en la app y elija Abrir. La app está compilada para Intel; los Mac con Apple Silicon la ejecutan mediante Rosetta.

Windows

Ejecute el instalador. Si SmartScreen muestra «Windows protegió su PC», pulse Más información → Ejecutar de todas formas. El zip portátil funciona sin instalar.

Cartera para Chrome

  1. Descomprima el archivo en una carpeta que vaya a conservar.
  2. Abra chrome://extensions y active el Modo de desarrollador.
  3. Pulse Cargar descomprimida y elija la carpeta descomprimida.

Verifique la suma de comprobación

shasum -a 256 -c SHA256SUMS.txt --ignore-missing     # macOS, Linux
certutil -hashfile Quinvium-2.16.0-Windows-x64.exe SHA256    # Windows

Descargue solo desde quinvium.com. Las compilaciones de otras fuentes pueden ser falsas. Las actualizaciones remotas están desactivadas en la mainnet, así que las nuevas versiones se instalan a mano desde esta página.
